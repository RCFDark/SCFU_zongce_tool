# 华南金融大学综测证明图片合成工具

把 PDF 的**首页**和**姓名所在页**左右拼接成一张图，方便交综测证明。
纯前端工具，**所有处理都在你自己的浏览器里完成，PDF 不会被上传到任何服务器**。

在线使用：<https://rcfdark.github.io/SCFU_zongce_tool/>

---

## 使用步骤

1. 用 **Chrome 或 Edge** 打开上面的网址（需要浏览器支持「文件系统访问」权限）。
2. 点右上角 **选择文件夹**，选中存放 PDF 的那个文件夹，点「允许」授权读写。
3. 左侧会列出文件夹里所有 PDF，自动从第一份开始：
   - **左栏**固定显示第 1 页；
   - **右栏**可翻页（`‹` `›` 按钮、页码框，或键盘 `←` `→`），翻到自己姓名所在那一页。
   - 右栏右下角有**缩放**（`−` `100%` `＋`），也可以用 `Ctrl + 滚轮`。放大后用滚轮 / 滚动条平移。
4. 在右侧页面上**按住鼠标拖出一个框**，套住自己的姓名。只有红边，不会有填充色遮挡文字。
5. 点 **保存并进入下一份**（或按 `⏎`），弹窗里选综测类型，图片自动写入 PDF 同目录下的文件夹，然后跳到下一份。

---

## ⚡ 自动识别（OCR）—— 不用手动翻页

选好文件夹后，点右上角 **⚡ 自动识别**，填入自己的姓名，点「开始」：

- 程序**逐份扫描**所有 PDF，自己找到姓名在第几页，自动画好红框，
  并**直接保存**到 `合成结果/`（自动模式统一按「未分类」存放，不建类型子文件夹）。
- **电子版 PDF 秒过**：先在文字层里直接取坐标，不跑 OCR。
- **扫描件走 OCR**：PP-OCRv5 模型在浏览器里本地推理，图片依旧不上传。
- 跑完后状态栏给出汇总；**识别不到的会标成「需手动」**，点「进入手动处理」会自动跳到那一份，你在右栏手动框一下即可。

### 关于加载

- 首次使用需下载约 **21MB** 模型（检测 4.8MB + 识别 16.6MB），之后浏览器会本地缓存，不再重复下载。
- 引擎自动在「本目录 → GitHub Pages → jsDelivr」之间择优回退加载。
- 页面首次打开会注册一个 Service Worker 来开启**跨源隔离**，从而让 onnxruntime 用多线程推理（约 2~3 倍提速）；首次会自动刷新一次，属正常现象。
- 若浏览器不支持多线程，会自动退化为单线程，功能不受影响，只是慢一些。

> 双击本地 html 文件（`file://`）也能用自动识别：此时模型会自动从线上地址加载，
> 因此**需要联网**（手动模式完全离线可用）。想要完全离线，请把 html 与
> `ocr-engine.js`、`charset.js`、`ocr-det.onnx`、`ocr-rec.onnx`、`ort.min.js`、
> `ort-wasm-simd-threaded.mjs`、`ort-wasm-simd-threaded.wasm` 放同一目录，
> 再用 Chrome 以 `--allow-file-access-from-files` 启动，或用任意静态服务器打开。

## 保存位置与文件名

| 选择的类型 | 保存到 |
| --- | --- |
| 德育 / 智育 / 体育 / 美育 / 劳育 | `合成结果/<类型>/` |
| 未分类 | `合成结果/`（不建子文件夹） |

- `合成结果` 文件夹会**自动创建**在 PDF 所在目录下，子文件夹同理。
- 输出文件名 = 原 PDF 文件名，只换扩展名：`2024级综测加分名单.pdf` → `2024级综测加分名单.jpg`。

## 输出规则

- **姓名在第 1 页** → 只输出这一页（带红框），不做拼接。
- **姓名在其它页** → 首页 + 姓名页**左右并排**拼成一张图。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `←` `→` | 翻页 |
| `Enter` | 保存并进入下一份 |
| `1` ~ `6` | 类型弹窗内直接选择 |
| `Esc` | 关闭弹窗 / 取消 |

## 其它

- 左侧列表会标记「已保存 / 已跳过 / 已有结果」，支持随时点任意一份重新处理，或「跳过此份」。
- 勾选「含子文件夹」可递归扫描子目录（自动跳过 `合成结果`）。
- 底部可调输出宽度：1200 / **1600（默认）** / 2200。人多、名单长的建议用默认。
- 「预览效果图」可以先看效果、确认文件名，再决定保存或返回修改。
- pdf.js 已随仓库提供（`pdf.min.js` / `pdf.worker.min.js`），**无需外网 CDN**，加载失败时才回退到公共 CDN。
- 自动识别所需的 OCR 组件也全部随仓库提供（`ocr-engine.js`、`charset.js`、`ocr-det.onnx`、`ocr-rec.onnx`、`ort.min.js`、`ort-wasm-simd-threaded.*`、`sw.js`）。

## 浏览器要求

「选择文件夹」依赖 **File System Access API**，需要：

- Chrome / Edge 86+ 桌面版（不支持 Firefox、Safari）
- **HTTPS 或 localhost** 环境 —— 所以用上面那个 GitHub Pages 网址即可；直接双击本地 html 文件也可以。

## 本地使用 / 部署

```bash
git clone https://github.com/RCFDark/SCFU_zongce_tool.git
cd SCFU_zongce_tool
# 直接用 Chrome 打开 index.html 即可，无需构建、无需 npm
```

**发布方式**：GitHub Pages「分支部署」，发布分支为 **`gh-pages`**，所以线上内容 = `gh-pages` 分支根目录。

更新工具后同步两个分支：

```bash
git push origin main
git push origin main:gh-pages     # 触发 Pages 重新发布
```

> `.nojekyll` 用于跳过 Jekyll 处理，保证 `pdf.min.js` 等文件原样提供。
