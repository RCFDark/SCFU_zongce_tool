使用说明

  1. 点击右上角 选择文件夹，选中存放 PDF 的那个文件夹（会申请读写权限）。
  2. 左侧列出文件夹里的所有 PDF，自动从第一份开始。
  3. 右边翻页找到自己姓名所在页，在上面按住鼠标拖出一个框，套住姓名（只描红框，不加底色）。
  4. 点 保存并进入下一份，先在弹窗里选综测类型（德育/智育/体育/美育/劳育/未分类）：
  • 选具体类型 → 存到 合成结果 / 该类型；选 未分类 → 直接存到 合成结果。
  • 姓名在第 1 页时，只输出这一页（不拼接）；在其它页时，首页 + 姓名页左右拼接成一张图。
  • 输出文件名 = PDF 同名，如 xxx.pdf → xxx.jpg。

快捷键：← → 翻页  ·  Enter 保存并下一份  ·  类型弹窗内 1~6 直接选  ·  Esc 关闭弹窗

姓名页右下角可缩放（50% ~ 400%，或按 Ctrl + 滚轮）；放大后拖到面板边缘会自动滚动。

不想手动翻页找名字？点右上角 ⚡ 自动识别：填入你的姓名，程序会用 OCR 逐份找到姓名页、自动画框并直接保存到 合成结果，识别不到的会自动转回本界面由你手动处理。

建议用 Chrome / Edge 打开本文件（需要「文件系统访问」权限），推荐直接把本 html 双击打开使用。

程序会逐份扫描 PDF：先在文字层里直接找（电子版秒过），找不到就用 OCR 识别后定位姓名， 自动画框并保存到 合成结果（不建类型子文件夹）。 识别不到的会标记为「需手动」，跑完后自动跳到那一份，你在右侧手动框一下即可。

填了学院关键词会先做一轮快扫：每页只认一部分框（先认长文本抓学院，再认姓名形状顺带碰名字）， 命中学院后只精查它前后各 2 页，而且快扫时撞到名字就直接定位——页数多的名单能快不少。 没填、或没扫到学院时自动退回逐页全扫，结果不受影响。

填写姓名后点「开始」。首次使用需下载约 20MB 模型，之后会本地缓存。
